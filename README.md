# JARVIS

## Vision

JARVIS is a personal AI operating system designed to assist with studying, software development, project management, gaming, and everyday productivity.

Unlike a traditional chatbot, JARVIS is built as a modular system where AI, memory, planning, tools, and automation work together.

## Tech Stack

- Java
- Spring Boot
- React
- FastAPI
- PostgreSQL
- Ollama
- Git
